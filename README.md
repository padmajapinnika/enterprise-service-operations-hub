# Enterprise Service Operations Hub

## Overview

The Enterprise Service Operations Hub (ESOH) is an end-to-end enterprise service request management solution built using Microsoft Power Platform.

The solution centralizes employee service requests, support team assignments, approval workflows, SLA monitoring, notifications and operational analytics.

## Business Problem

Organizations often manage internal service requests through emails, spreadsheets and disconnected communication channels. This can lead to poor request visibility, delayed responses, manual follow-ups and limited operational reporting.

ESOH aims to address these challenges through a centralized low-code business application platform.

## Technology Stack

- Microsoft Dataverse
- Microsoft Power Apps (Canvas and Model-driven Apps)
- Microsoft Power Automate
- Microsoft Power BI
- Power Platform CLI
- GitHub

## Planned Features

- Employee self-service request submission
- Service request tracking and assignment
- Support team and department management
- Manager approval workflows
- SLA monitoring and escalation
- Automated notifications
- Executive and operational dashboards
- Solution lifecycle management and deployment

## Architecture

The solution uses Microsoft Dataverse as its central data platform, Power Apps for user experiences, Power Automate for business process automation and Power BI for analytics.
